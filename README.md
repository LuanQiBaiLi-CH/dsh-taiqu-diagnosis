# dsh-taiqu-diagnosis

台区线损与台区异常的**确定性**诊断插件，给 DeepSeek Harness 的 Host 用。

导出的台区报表里，线损率出错多半源于数据没洗干净：同一日期同一块表两条记录，售电量翻倍，一个 3% 的台区能算成 -30%。这个插件先做去重，再算线损，然后把"一台区多终端"这类结构异常和线损异常放在两张表里分别陈述，最后才做关联。

所有数字来自工作簿本身或调用参数。没有默认阈值，没有经验值，缺什么就报缺口。

## 为什么是插件而不是一段提示词

线损判定有两个东西不能交给语言模型：算术和阈值。

- 算术：供售电量相除、去重后的差值、跨表计数，模型心算会漂。
- 阈值：多少算高损是各单位的考核口径，模型不该替用户决定。

所以计算放在 Python 里，阈值只从调用参数进。用户不传，规则状态就是 `GAP`，报告里明写"未提供该参数，只列事实"。

## 安装

需要 Python 3 与 `openpyxl`：

```bash
python3 -m pip install openpyxl
```

把仓库克隆到工作区任意位置，然后用 Harness 的插件管理器安装本地目录：

```
plugin_manager(action="install_bundle", target="<仓库绝对路径>")
```

装完即可用，无需重启。（改 `index.js` 需要重启加载新模块；改 `lib/engine.py` 即时生效，因为每次调用都是新进程。）

卸载：`plugin_manager(action="remove_bundle", target=...)`。

## 两个工具

### `taiqu_scan`

只读扫描，不判异常。

| 参数 | 说明 |
|---|---|
| `file` | 工作簿绝对路径 |
| `sheet` | 可选，工作表名；缺省自动挑表头命中最多的一张 |

返回：工作表清单、真实表头行、列名、字段角色映射、数据行数、日期范围、重复行统计。表头行是按关键词命中数探测的，因为导出表的第一行常是标题。

### `taiqu_diagnose`

| 参数 | 说明 |
|---|---|
| `file` / `sheet` | 同上 |
| `mapping` | 可选，覆盖字段角色：`tgId` `tgName` `date` `terminal` `meter` `mp` `customer` `ratio` `tgFlag` `supply` `sale` `lossRate` |
| `params` | 可选，阈值与口径 |

`params` 只认这几个键：

| 键 | 含义 |
|---|---|
| `n_term_multi` | 一台区多终端的终端数下限 |
| `n_tai_multi` | 一终端多台区的台区数下限 |
| `th_loss_high` | 高损阈值（百分数） |
| `th_loss_neg` | 负损容差（百分数） |
| `win_stat` / `series_min` | 统计周期标签 / 持续期数 |

返回七部分：重复行（含去重前后线损率差）、台区线损重算、A1、A2、A3、B1/B2、缺口清单。

## 五条规则

| 编号 | 规则 | 需要阈值 |
|---|---|---|
| A1 | 同一台区编号下挂多个终端 | `n_term_multi` |
| A2 | 同一终端覆盖多个台区（读终端台账的跨台区数） | `n_tai_multi` |
| A3 | 户表采集终端不属于本台区总表终端 | 否 |
| B1 | 线损率高于阈值 | `th_loss_high` |
| B2 | 负损（线损电量 < 0，即售电 > 供电） | 否，容差可选 |

A1 和 A2 互为镜像。档案把归属写成多值存储时，两条会同时命中，报告需要说明这是同一个结构问题的两面，不是两个缺陷。

A3 是 A1 真正指向的问题：终端数量多本身不是错，户表的采集终端和本台区总表终端不是同一台，才是。

## 口径

- 电量列分两种：`Pap R` 是正向有功示数，要日差分再乘综合倍率；`Pap E` 已是 kWh 日电量，再乘倍率就错。
- 去重键是日期 + 电表条码；判据是两条记录仅测量点号不同（一空一有值），电量相同。
- 线损率 = (总表电量 − Σ户表电量) ÷ 总表电量 × 100%。

这些是行业常见写法，不一定等于本单位的统计口径。插件把它们当成可覆盖的实现，不写成结论。

## 边界

- 只读 `.xlsx`。`.xls` 走 pandas，需要 `xlrd`，失败会提示先转换。
- 只有 `Pap R` 示数、没有日电量列的表，不做跨日差分，直接报缺口。宁可不出数，不出错的数。
- 不带阈值时不会出现"高损""负损"这类判定词，只有分布。
- 结论只到"命中规则 + 事实"。窃电认定、责任划分不在范围内。
